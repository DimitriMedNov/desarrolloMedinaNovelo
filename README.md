# Patrones de diseño en Java

Catálogo de patrones de diseño implementados en Java con Maven, cada uno con un caso de uso concreto en lugar de un ejemplo abstracto. Proyecto de la Universidad Anáhuac Mayab.

## Los patrones, por tipo

### Creacionales
| Patrón | Caso |
|---|---|
| **Builder** | Construir un objeto con muchas partes opcionales sin un constructor de diez parámetros |
| **Factory Method** | Conectarse a MySQL, Oracle, MongoDB o CouchDB sin que el código que la usa sepa cuál es |
| **Singleton** | Una sola instancia compartida |

### Estructurales
| Patrón | Caso |
|---|---|
| **Proxy** | Un manejador de archivos que valida permisos antes de dejar pasar la operación |
| **Decorator** | Agregar comportamiento a un objeto sin tocar su clase |

### De comportamiento
| Patrón | Caso |
|---|---|
| **Template Method** | El mismo procedimiento leyendo clientes desde Excel o desde JSON |
| **Adapter** | Hacer que dos interfaces incompatibles trabajen juntas |
| **Strategy** | Cambiar el criterio de ordenamiento de transacciones bancarias sin tocar quien ordena |
| **Observer** | Avisar a varios interesados cuando algo cambia |

Cada patrón lleva su diagrama de clases.

## Stack
